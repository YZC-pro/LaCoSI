# LaCoSI
Official implementation of LaCoSI. This repository currently provides a partial release of the code. The complete implementation will be made publicly available upon acceptance of the paper.


## Network Architecture 

LaCoSI retains the original agent backbone, latent coordination learner, message encoder, individual Q network, and QMIX mixer, while introducing only a lightweight counterfactual value-of-information estimator. For each agent, the 204-dimensional local observation is first projected to 64 dimensions through a linear layer followed by ReLU, and the resulting feature is processed by a GRUCell with hidden size 64 to obtain the recurrent representation \(h_i^t\). The latent coordination representation adopts a teacher--student architecture. The student view network is implemented as an MLP with dimensions \(204 \rightarrow 128 \rightarrow 64\), followed by a projection network of \(64 \rightarrow 64 \rightarrow 16\), producing 16 logits for the latent coordination distribution \(P_i^t\). The teacher network uses the same architecture and is updated by exponential moving average. The inferred discrete coordination category is mapped to a 4-dimensional embedding and then processed by an MLP of \(4 \rightarrow 64 \rightarrow 64\), producing a 64-dimensional coordination feature for action-value estimation.

Teammate messages are generated from the 64-dimensional recurrent hidden states using a linear message encoder of \(64 \rightarrow 16\) followed by a Tanh activation. For each receiver, the messages from the other available agents are mean-pooled into a 16-dimensional candidate teammate representation \(\tilde m_i^t\). The latent coordination statistics \(\xi_i^t=[u_i^t,v_i^t]\) form a two-dimensional input to the CVoI estimator \(F_\phi\), which is implemented as a lightweight MLP with dimensions \(2 \rightarrow 16 \rightarrow 1\). Its scalar output \(\hat d_i^t\) represents the predicted decision value of teammate information and is thresholded to obtain the receiver-side incorporation gate. The resulting gated teammate representation remains 16-dimensional.

For individual action-value estimation, the 64-dimensional recurrent feature, the 64-dimensional coordination feature, and the 16-dimensional gated teammate representation are concatenated into a 144-dimensional input. The individual Q head maps this feature directly from 144 dimensions to 18 action values. The target individual Q head uses the same architecture as the online Q head. In the counterfactual value construction, this target Q head is reused under two information conditions: one input contains the candidate teammate representation \(\tilde m_i^t\), while the other replaces the message with a 16-dimensional zero vector. Therefore, the counterfactual branch does not introduce an additional individual Q network.

The centralized value function follows QMIX with a mixing hidden size of 64. In a 10-agent setting, the mixer receives one scalar individual Q value from each agent, while the global state is provided to the QMIX hypernetwork to generate state-dependent mixing parameters. The target mixing network has the same architecture as the online mixer. During counterfactual value construction, the same target mixer evaluates the information-present individual-value vector and the corresponding counterfactual vector in which only the receiver's value is replaced by its information-absent counterpart. These two evaluations produce \(V_+^t\) and \(V_{-i}^t\), from which the counterfactual information-value target \(d_i^t=[V_+^t-V_{-i}^t]_+\) is obtained. Overall, the new mechanism preserves the original agent and QMIX network dimensions, and the only additional learnable component is the lightweight CVoI estimator with architecture \(2 \rightarrow 16 \rightarrow 1\). The counterfactual branch reuses the existing target individual Q network and target QMIX mixer, adding only extra forward evaluations rather than additional Q-network or mixer parameters.
